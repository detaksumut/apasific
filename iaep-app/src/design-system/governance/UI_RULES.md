# APASIFIC Design System Governance Rules

## Rule 1 — Presentation Only
**Frontend is strictly a presentation layer.**
`Display → Interact → Request → Render`
Frontend code must NEVER contain business logic, domain calculations, or direct database mutations.

## Rule 2 — Enterprise Consistency
All modules (Command Center, Researcher Profile, Institution Portal, Publication Workflow, Reviewer Workspace, AI Assistant) MUST use the **APASIFIC Design System**. Do not use ad-hoc colors or unstructured CSS.

## Rule 3 — Intelligence Visualization Standard
Standardized visual patterns must be maintained for:
1. **Reputation Score**: Gold accent, large typography.
2. **Knowledge Graph**: Interactive nodes connected by edges, academic-blue or gold-light strokes.
3. **AI Prediction**: Purple/Emerald accents, glassmorphism cards, explicit confidence badges.
4. **Impact Metrics**: Clear progress bars or numeric trends.

## Rule 4 — Governance Disclaimers
Any AI-generated recommendation must be accompanied by a governance disclaimer enforcing the **AI as Advisor, Human as Authority** principle.
