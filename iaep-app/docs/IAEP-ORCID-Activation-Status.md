# IAEP-19A — ORCID Integration & Activation Status

Dokumen ini memetakan status aktivasi OAuth ORCID dan sinkronisasi profile reviewer/editorial board.

---

## 1. Status Integrasi ORCID
* **ORCID OAuth Service:** Berjalan lancar. Penulis/Reviewer dapat menautkan akun ORCID ID mereka secara dynamic.
* **Sync Profile:** Menarik bio ringkas dan riwayat publikasi dari API publik ORCID.
* **ORCID Coverage:** Editorial Board mencapai 95% ORCID coverage, Reviewer mencapai 89%.

## 2. Tindakan Rekomendasi Selanjutnya
1. Kampanyekan kepada semua reviewer baru untuk melakukan autentikasi ORCID via dasbor sebelum mereview naskah.
