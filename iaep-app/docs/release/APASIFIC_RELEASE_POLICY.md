## 🛡️ PRODUCTION SAFETY PRINCIPLE

APASIFIC IAEEA saat ini diperlakukan sebagai *production-bound academic infrastructure*.

**Prinsip utama:**
*Preserve First, Change Second.*

Jika terjadi konflik antara melakukan perubahan yang berpotensi meningkatkan sistem, ATAU mempertahankan stabilitas sistem, maka keputusan wajib:
**STABILITY > IMPROVEMENT**

### Emergency Exception
Perubahan tanpa *Change Request* hanya diperbolehkan apabila:
- Sistem tidak dapat start
- Login seluruh pengguna gagal
- Data corruption terjadi
- Security vulnerability kritis ditemukan
- Production outage terjadi

Dalam kondisi tersebut:
1. Dokumentasikan kejadian.
2. Buat emergency change record.
3. Terapkan minimal patch.
4. Verifikasi kembali.
