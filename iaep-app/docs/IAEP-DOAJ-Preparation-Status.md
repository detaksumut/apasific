# IAEP-19A — DOAJ Indexing Preparation Status

Dokumen ini memetakan kelengkapan kriteria jurnal untuk pengajuan indeksasi ke Directory of Open Access Journals (DOAJ).

---

## 1. Evaluasi Kriteria DOAJ

| Persyaratan DOAJ | Status Kesiapan | Lokasi Pembuktian |
| :--- | :---: | :--- |
| **Editorial Policy** | ✅ READY | Halaman `/policies/editorial` |
| **Publication Ethics**| ✅ READY | Halaman `/policies/ethics` |
| **APC Policy (Free)** | ✅ READY | Halaman `/policies/charges` |
| **Licensing (CC-BY)** | ✅ READY | Footer & Detail Artikel |
| **OJS Metadata** | ✅ READY | Dublin Core & OpenGraph tags |

---

## 2. Tindakan Rekomendasi Selanjutnya
1. Tunggu hingga eISSN diterbitkan resmi oleh Perpusnas RI.
2. Jurnal harus memiliki minimal 1 tahun riwayat terbitan teratur atau minimal 2 issue lengkap sebelum submit proposal DOAJ.
